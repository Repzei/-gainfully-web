# Emneliste for indholdsagenten

Agenten tager det øverste emne med `[ ]`, skriver det og sætter `[x]` med dato og branch.
Jesper må frit omprioritere, tilføje eller slette emner. Søgeord er udgangspunkter: agenten
tjekker selv søgeresultaterne og vælger den formulering folk faktisk bruger på hvert sprog.

Prioritering: emner hvor Gainfully naturligt hjælper (tracking, progression, programmer,
plateau, statistik) kommer først. Rene kost- eller livsstilsemner kommer sidst.
