O que é 1RM?

1RM (one rep max) é o peso máximo que você consegue levantar para exatamente uma repetição completa com técnica correta. É o padrão-ouro para medir a força absoluta na academia.

Seu 1RM é a base de todos os programas de treinamento baseados em percentuais. Seja um 5/3/1, progressão linear ou um programa de powerlifting - tudo é calculado a partir do seu 1RM.

As três fórmulas

Epley (1985)
1RM = peso x (1 + repetições / 30)
Brzycki (1993)
1RM = peso x (36 / (37 - repetições))
Landers (1985)
1RM = peso / (1,013 - 0,0267123 x repetições)

Usando seu 1RM no treinamento

Desenvolvimento de força

Trabalhe a 85-95% do seu 1RM para 1-5 repetições. Esta faixa desenvolve a força máxima e melhora as adaptações neurológicas.

Hipertrofia (crescimento muscular)

Trabalhe a 67-85% do seu 1RM para 6-12 repetições. Esta faixa maximiza o crescimento muscular.
